# Swarm Debugger Roadmap

This document outlines the planned development milestones for Swarm Debugger.

## Milestone 1: MVP (Complete)
- [x] Basic project architecture (Next.js, Tailwind CSS)
- [x] Local working application
- [x] Input form for code and error messages
- [x] Mock AI agent responses for debugging analysis

## Milestone 2: Agent Integration (Complete)
- [x] Connect to real AI models (OpenAI/Gemini/Anthropic)
- [x] Implement true multi-agent orchestration (Planner, Debugger, Reviewer)

## Milestone 3: Visualization (Complete)
- [x] Agent execution timeline visualization
- [x] Real-time status updates as agents work
- [x] Polished UI with loading states and code highlighting

## Milestone 4: Repository Support (Current)
- [ ] Allow uploading or connecting full GitHub repositories instead of single snippets

## Milestone 5: Automated Testing
- [ ] Test execution agent to verify fixes against user-provided tests

## Milestone 6-10: Advanced Features
- [ ] Patch generation and direct GitHub PR creation
- [ ] Verification agent
- [ ] History and debugging sessions
- [ ] Beautiful demo experience
- [ ] Production deployment
